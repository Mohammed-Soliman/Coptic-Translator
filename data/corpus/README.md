# Coptic corpus data

## `ud_coptic_scriptorium/`

`dev.conllu` and `test.conllu` are the dev/test splits of the **UD Coptic
Scriptorium** treebank (Sahidic dialect), downloaded from:

https://github.com/UniversalDependencies/UD_Coptic-Scriptorium

**License: CC BY 4.0.** If you publish anything built from this data, cite:

> Zeldes, Amir & Abrams, Mitchell (2018). "The Coptic Universal Dependency
> Treebank". In: Proceedings of the Universal Dependencies Workshop 2018.
> Brussels, Belgium, 192-201.

785 sentences, 21,335 tokens, manually annotated (part of speech, lemma,
syntax), most with an English sentence-level translation.

The much larger `train.conllu` split isn't bundled here to keep the repo
small. Grab it yourself if you need it:

```bash
curl -o ud_coptic_scriptorium/train.conllu \
  https://raw.githubusercontent.com/UniversalDependencies/UD_Coptic-Scriptorium/master/cop_scriptorium-ud-train.conllu
```

Then re-run the scripts in `training/preprocessing/` to regenerate
`data/parallel/scriptorium_gold.csv` and `lemma_frequencies.json` including
the extra data.

## `lemma_frequencies.json`

Generated by `training/preprocessing/export_lemma_frequencies.py`. A
frequency-ranked list of (lemma, part-of-speech) pairs actually attested in
the treebank. **This is not a dictionary** - the treebank has sentence-level
English translations only, not word-level glosses, so there's no automatic
way to know what each lemma means in English without either:

1. A real word-alignment step (e.g. running `fast_align` or similar over
   `scriptorium_gold.csv`'s English/Coptic sentence pairs), or
2. Manual glossing, prioritized by frequency (the most-common ~50 lemmas
   here would give outsized coverage gains in `data/dictionary/`).

Either is a reasonable next step, but don't skip straight to inventing
English glosses for these lemmas without one - see the honesty note in
`ARCHITECTURE.md`.

## Regenerating derived files

```bash
python -m training.preprocessing.build_parallel_from_treebank
python -m training.preprocessing.export_lemma_frequencies
```

Both scripts read every `*.conllu` file in `ud_coptic_scriptorium/`, so
adding `train.conllu` and re-running picks it up automatically.
